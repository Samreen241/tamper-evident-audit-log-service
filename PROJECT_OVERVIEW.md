# Audit Log Service

Tamper-evident audit log service prototype for the interview assignment.

## Project status

Milestone 1 - repository and working agreement.

## Planned capabilities

- Append-only audit event ingestion
- Filtered and paginated event queries
- Hash-chain verification and tamper detection
- Retention, redaction, and verifiable export
- Compliance access reporting

## Development process

Requirements, design decisions, validation evidence, and AI-assisted development notes are kept in this repository as the project progresses.

## Local setup

Setup and run instructions will be added with the application scaffold in the next milestone.

## Confidentiality

This repository is private and is intended only for the assessment reviewers and the candidate. Do not commit the supplied assignment document or other confidential assessment material.
